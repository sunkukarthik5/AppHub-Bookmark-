AppHub is a modern, responsive web application that helps users organize, manage, and access all their applications in one place.
It provides category-based app management, favorites, search functionality, dark mode, and a clean UI similar to a personal app launcher.

📌 Features

🧭 Centralized App Dashboard

🔍 Search Apps (Desktop & Mobile)

📂 Category Management

❤️ Favorites Support

🕒 Recent Apps Section

🌙 Dark / Light Mode Toggle

➕ Add Apps & Categories

👤 Profile Management

📱 Fully Responsive Design

💾 LocalStorage Support (No backend required)
